Change log · v0.7

Prototype changelog

v0.7 · Collaborative open questions

  • Made Open Questions collaborative and editable through Supabase.
  • Added Add open question form with initials, category, and question text.
  • Added Open / Resolved / All filters plus resolve, unresolve, and delete actions.
  • Added SQL seed rows for the existing MVP questions with fixed IDs.

v0.6 · Sticky CTA cleanup

  • Moved recommendations, product, and order purchase CTAs out of the scroll content and into phone-level bottom bars.
  • Anchored purchase bars above the bottom navigation so they feel intentional and consistent.
  • Added extra scroll padding on purchase screens so page content can clear the bottom action area.

v0.5 · Comment mode refinement

  • Reintroduced Comment Mode so normal prototype interactions still work when commenting is off.
  • Clicking Add comment now turns on placement mode with a clear banner and screen hover affordance.
  • Clicking a screen in Comment Mode places a temporary pin and opens the comment composer.
  • Saved pins can be dragged to a new location in Comment Mode and persist updated coordinates to Supabase.
  • Canceling removes the temporary pin; saving keeps the pin and highlights the new comment.
  • Added screen-level comment badges and kept Add general comment as a fallback for unpinned feedback.

v0.4 · Care plan refinement

  • Simplified the post-clinician care plan state to avoid repeated recommendation CTAs.
  • Changed the top care plan CTA to View Care Plan.
  • Replaced generic supplement examples with prescription recommendations: Estradiol Patch and Semaglutide.
  • Moved Prescription Recommendations above LifeScore and Lab Reports in the post-clinician state.
  • Updated the labs/no-member card copy to use user-facing biomarker testing language and removed TBD chips from the mobile UI.

v0.3 · MVP state model pass

  • Updated dashboard states to reflect the May 15 operational journey.
  • Added labs/no-member and blood-draw-booked states.
  • Changed blood draw terminology to Schedule Blood Draw.
  • Hid Health Questionnaire from the unscheduled member no-labs state.
  • Split labs processing by questionnaire incomplete vs complete.
  • Removed next-draw-due logic and LifeForce membership management from dashboard states.

v0.2 · Pre-MVP state update snapshot

  • Snapshot created before May 15 meeting-driven state model changes.
  • Current prototype includes dashboard states, reports/results, recommendations/products, and collaborative comments.
  • This is the baseline to revert to if the next round of changes goes in the wrong direction.

Upcoming / in progress

  • Clarify non-member primary CTA strategy.
  • Confirm one-off labs entitlements.
  • Confirm supplement purchase path and pre-clinician recommendation rules.
  • Define ULC service recommendation rules and deep links.
